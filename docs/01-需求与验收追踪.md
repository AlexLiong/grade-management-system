# 需求与验收追踪

本文把课程要求转换为可演示、可测试的验收项。最终代码中的页面、REST 接口、RMI 接口和测试必须能够回指本表，避免出现“文档有设计、程序无实现”的情况。

## 1. 角色与业务范围

| 编号 | 原始需求 | 系统行为 | 主要验收证据 |
| --- | --- | --- | --- |
| T-01 | 教师录入百分制成绩 | 课程开课记录只使用百分制；单项分数限制为 0~100 | 教师成绩录入页、请求校验测试 |
| T-02 | 设置平时、考勤、作业、实验、期中、期末系数 | 每个开课班独立保存评分方案，所有权重之和必须为 100 | 权重编辑页、`TeacherCourseServiceWeightTest` 测试 |
| T-03 | 区分正考和补考 | 两个字段分别录入，补考卷面分保留，学生成绩显示时按 60 分封顶 | 教师录入页、学生成绩页、边界测试 |
| T-04 | 暂存、提交、撤销、查看 | 正考与补考分别暂存、提交和撤回；教师只能编辑对应草稿；管理员另有受审计的小撤销与双人复核大撤销 | 状态流转接口与越权测试 |
| T-05 | 成绩统计、分析录入和显示 | 自动生成均值、中位数、标准差、分段分布、及格率；教师保存分析文字 | 分析页及统计测试 |
| T-06 | 教师查询往年课程 | 按课程名、学年、学期组合筛选并分页 | 历史课程页及分页测试 |
| S-01 | 学生查看本人本学期成绩 | 服务端从登录身份取得学生编号，不接受前端指定他人编号 | 学生首页与资源所有权测试 |
| S-02 | 学生查看在校成绩一览 | 展示全部已提交成绩，正考/补考用 `正考/计分补考` 表示 | 成绩一览页及补考规则测试 |
| S-03 | 学生查看本人排名 | 仅在同一开课班已提交成绩中计算名次和总人数 | 排名接口测试 |
| S-04 | 挂科红灯预警、打印 | 不及格课程突出显示；使用浏览器打印样式输出一览表 | 学生页面、打印样式 |
| A-01 | 管理员小撤销 | 已提交成绩恢复为草稿，保留数据，教师可以再次编辑和提交 | 撤销确认框、状态流转测试 |
| A-02 | 管理员大撤销 | 删除业务成绩记录，但数据库外账本保留操作前快照和完整审计 | 二次确认、恢复证据测试 |
| A-03 | 人员组织库维护 | 管理教师、学生和管理员的基本资料、启停状态与角色 | 用户管理页、CRUD 测试 |
| A-04 | 权限分配 | 在角色默认权限基础上分配查询、录入、维护、审计等细粒度权限 | 权限编辑页、权限矩阵测试 |
| A-05 | 数据库外查原始成绩 | 管理员可验证链、查看受保护的原始快照并执行受审计恢复 | 完整性页面、篡改与恢复测试 |

## 2. AI 与智能辅助

| 编号 | 要求 | 落地规则 | 数据边界 |
| --- | --- | --- | --- |
| AI-01 | 成绩异常检测 | 检测历史班均值绝对偏移 `>=10`、`均值 +/- 3 sigma`、低高百分位、个人历史剧烈波动、补考卷面分 `<30` 或 `>90` | 异常写审计和告警；管理员复核 |
| AI-02 | 线性回归预警 | 使用同课程至少三个学年的平时、实验、期末样本拟合 `final = a*daily + b*lab + c` | 按需计算，不写正式成绩表 |
| AI-03 | 决策树预警 | 从历史样本学习可解释阈值分支，返回预测值、风险等级和规则树文本 | 仅本人和授课教师可查看个人结果 |
| AI-04 | 趋势阈值 | 预测总评或期末低于 55 分时给出高风险；预测期末比历史样本期末均值低 `>=10` 分时提示 | 结果只存在本次响应，不持久化派生告警 |
| AI-05 | 智能录入 | 支持表格粘贴、CSV、浏览器语音识别；云 OCR 通过受控适配器接入 | 图片限制类型和大小，只在内存处理，用后释放；未配置云服务时明确不可用 |
| AI-06 | 操作序列异常 | 识别深夜批量操作、高频撤销、非授课教师操作等可解释模式 | 仅使用最小化审计元数据，不读取密码或令牌 |

## 3. 分布式后台

| 编号 | 要求 | 实现约束 | 失败语义 |
| --- | --- | --- | --- |
| R-01 | 物理分布、逻辑统一 | Web 后端是 RMI 客户端宿主；RMI 数据服务为独立 JVM，唯一持有数据库连接 | 任一进程可独立启动和停止 |
| R-02 | 查询与操纵分离 | `SelectInterface` 返回 `String[][]`；`ManipulationInterface` 返回 `boolean` | 查询失败抛远程异常；`false` 仅表示已确定回滚 |
| R-03 | 值传递对象 | 表资源键、字段、过滤器、分页、操作枚举和字段值均是可序列化 DTO | 协议 DTO 有版本号和 `serialVersionUID` |
| R-04 | 自动形成 SQL | RMI 服务端根据结构化命令和 schema 允许列表生成 SQL | 前端、REST 和 RMI DTO 均不能携带裸 SQL |
| R-05 | SQL 类型安全 | 标识符只来自允许列表，所有值使用 `PreparedStatement` 参数绑定 | 注入载荷只能成为普通参数值 |
| R-06 | 多语句事务 | 一次远程批请求在一个本地数据库事务中执行 | 任意命令失败则全部回滚 |
| R-07 | 分页与跨表视图 | 查询请求包含页码、页长；跨表数据由 Web 服务发起多次允许列表查询组装，或由 RMI 白名单中的严格只读领域视图完成数据库计数与分页 | 非法排序、字段、过滤器或未受权视图立即拒绝 |
| R-08 | 数据库适配 | 数据源由 Spring 配置；分页和标识符差异由方言隔离 | 默认验证 H2；其他数据库的未实测范围必须如实标明 |
| R-09 | 远程安全 | 请求签名、时间窗、随机数防重放、反序列化白名单、固定端口、网络隔离；生产启用 TLS | 签名错误、过期、重放和未知类均失败关闭 |

## 4. 安全验收

| 编号 | 控制 | 具体措施 | 反向测试 |
| --- | --- | --- | --- |
| SEC-01 | 身份认证 | BCrypt 密码摘要；短期 JWT 置于 `HttpOnly`、`Secure`、`SameSite` Cookie | 错误密码、篡改令牌、过期令牌 |
| SEC-02 | CSRF | Cookie 会话凭据配合 CSRF Token 和自定义请求头 | 缺少或伪造 token 的写请求 |
| SEC-03 | 登录防护 | 用户名/IP 维度限速，认证失败不泄露用户是否存在 | 连续错误登录 |
| SEC-04 | 后端授权 | 角色、细粒度权限和资源所有权三层校验；RMI 服务端二次校验 | 学生查他人、教师改他课、无权限管理员 |
| SEC-05 | 传输安全 | 浏览器生产入口使用 HTTPS；RMI 生产使用 TLS 或受隔离网络中的签名信封 | HTTP 降级、未受信证书、无效签名 |
| SEC-06 | 存储保密 | 成绩分量使用 AES-GCM 加密；密钥来自环境变量或权限受限的运行时文件 | 直接查看数据库不可读出明文成绩 |
| SEC-07 | 完整性 | 每条成绩有 HMAC；提交/撤销写数据库审计和数据库外哈希链 | 修改成绩密文、nonce 或 HMAC 后读取解密失败；修改账本中间条目后链校验失败。链校验不自动发现数据库行删除或非加密元数据变更 |
| SEC-08 | SQL 注入 | 资源与字段允许列表、参数绑定、请求校验 | `' OR 1=1 --`、危险标识符和操作符 |
| SEC-09 | XSS | Vue 文本插值、禁止动态 HTML、安全响应头和 CSP | 分析文字中的脚本载荷 |
| SEC-10 | 审计最小化 | 记录主体、动作、资源、结果、请求号和时间；不记录密码、JWT、密钥 | 日志敏感信息扫描 |
| SEC-11 | 可用性 | 分页上限、请求体上限、OCR 文件上限、RMI 超时/健康检查、统一错误响应 | 超大页长、超大图片、RMI 不可用 |
| SEC-12 | 密钥管理 | 仓库无真实密钥；首次运行生成随机本地密钥；生产环境变量覆盖 | 源码秘密扫描、缺失生产密钥启动失败 |

## 5. 状态与关键不变量

1. 评分权重总和必须精确等于 100；无效方案不能保存。
2. 所有分数均为 0~100；用于总评的补考成绩为 `min(补考卷面分, 60)`。
3. 教师只可操作本人授课开课班；学生只可读取本人；管理员也必须具有相应细粒度权限。
4. `SUBMITTED` 成绩不可被教师直接修改；小撤销后才可改；大撤销后业务记录不存在。
5. 大撤销不能删除数据库外账本证据；恢复操作本身必须再次追加审计事件。
6. AI 预测不得写入正式成绩表，不得成为自动改分依据。
7. RMI 服务不可用时 REST 返回明确的服务不可用错误，不得静默改走本地数据库。
8. 相同幂等键的写请求不得重复落库；乐观版本冲突不得覆盖后写入。
