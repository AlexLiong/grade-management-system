一、概述
综合实践（网络软件与安全）面向一个 Web 系统展开 Web 前端
功能与后台功能的设计与开发任务。 Web 前端主要向用户展示一个高
校成绩管理系统的基本功能，后台须对Web 前端提交数据进行处理。
整个系统须从网络数据传输安全、数据持久存储安全、操作访问权限
控制、敏感数据在网络空间不可篡改等方面进行安全设计。
每组学生根据自身人员组成以及技术能力，用面向对象方法学建
模方法和工具进行分析和设计，并选择合适的面向对象语言全部实现
或部分实现功能，并给出相应的测试结果，指导教师根据各组学生完
成代码以及文档的质量进行综合实践评分。

（1）基于 Web 的高校成绩管理系统功能需求
系统角色包括教师、学生和管理员。教师主要负责录入考试成绩、

台功能不具有“分布式部署能力”时，综合考核将直接降档次评估。

系统功能须从 Web 前端页面功能安全、数据传输安全、操作访

面进行安全权衡并给出安全性措施和相应的安全测试。这部分功能是

1.高校成绩管理系统背景
高等院校担负着我国培养专门人才的重要任务，高校教务管理
部门作为教育教学实施中的主要管理部门，日常需要完成各类各专
业学生的教学管理、教务管理等繁琐复杂的事务性工作。近年来，
随着信息技术的飞速发展，高校教务管理信息化进程也不断推进，
尤其是大量教学管理相关计算机软件的普遍应用，信息化程度正在
不断深化，其中基础课程、专业课程教学的 CAI软件，学生管理、
学籍管理、成绩管理等教务管理软件的发展与应用日趋成熟。
然而，许多高校在教务管理办公过程中，却依然沿用着传统人
工管理的工作方式处理教材管理、实验管理、实践教学管理、考务
管理、教师工作量管理、教学检查、教学研究及研究生管理等方面
的业务。这些业务信息在办公过程中会频繁使用，尤其是业务问询
十分频繁，文件及资料的查阅频度也相当高。对此，人工管理方式
在管理效率与效能方面的制约是十分明显的。不仅使办公人员长期
处于很高的工作强度的压力之中，同时也越来越明显地形成了办公
对教学管理服务的瓶颈，因此对这种现状的改变已经成为当前亟待
解决的问题。
因此我们拟设计并开发一套高校教务管理办公系统软件，通过
对以上问题的深入调研、分析，挖掘其中存在的有价值的信息与联
系，运用已有的数据库知识结合软件设计技术、方法与工具，设计
并完成该办公系统软件及其文档，力求能够对解决实际问题产生有
效的帮助。

五、系统后台远程方法调用具体要求
后台选用一种或几种结合的远程方法调用技术，即CORBA
（对象请求代理）、DCOM（分布式组件对象模型）、JMS（Java 消
息服务）、RMI（远程方法调用）、Webservice（Web 服务）等，设计
远程方法调用客户端和服务端，从而体现“物理上分布，逻辑上统
一”的网络软件的分布式结构特征。
1 远程方法调用客户端
 客户端宿主是一个可处理 Web 前端 HTTPS 请求统一入口
的容器。
 客户端实现对 Web 前端功能传来的数据统一处理。Web
前端无论是插入功能页面、修改功能页面、删除功能页面
以及查询功能页面都统一提交至远程方法调用客户端。客
户端采用合适的数据结构对象存放和表达相应的功能数
据，包括但不限于数据字段、数据值、表名以、SQL 查询
以及SQL 操作语句的类型（Insert、Update 和 Delete），这
里的数据查询语句不与数据操纵语句混合。
 在客户端和Web 前端页面建立数据命名约定，从而使客
户端能识别Web 前端传来数据的关键字和非关键字，也
要考虑对多表进行多类型操作的可能性，也可考虑对多表
进行有关联查询的可能性。
 客户端针对SQL 查询以及SQL 操作语句的类型分别调用
服务端的SelectInterface 或 ManipulationInterface 远程接
口，并将数据结构对象值传递到服务端。

六、系统安全性具体要求
1 软件开发与网络安全的关系
在软件开发过程中，网络安全设计占据着至关重要的地位。软
件开发与网络安全之间存在着密不可分的联系，一方面软件开发者
负责构建各类网络应用系统（如学生成绩管理系统），为用户提供便
利的功能与服务；另一方面，网络安全作为软件开发过程中的重要
环节，确保软件应用的安全性和用户数据的保密性。
（1）软件开发与网络安全之间关系：
 功能性与安全性的平衡
 安全漏洞与风险评估
 安全编码实践的重要性
 软件测试与漏洞检测
 持续监控与更新
（2）网络安全设计的原则
 安全性：网络安全设计应确保网络系统的完整性和可靠
性，防止数据被篡改或破坏。
 可用性：网络安全设计应确保网络系统的可用性，使用户
能够正常地访问和使用网络资源。
 保密性：网络安全设计应确保网络应用系统中敏感数据的
保密性，防止数据泄露给未经授权的用户。
（3）网络安全设计的主要内容

 网络隔离：通过防火墙、入侵检测系统等技术手段，将网

件对各种网络安全威胁的防范能力。在《基于Web的成绩管理系
统》的设计中，可以从以下七方面考虑：
 身份认证模块（如支持多种身份验证方式，确保用户身份
的真实性）
 访问控制模块（对用户访问系统资源的权限进行管理，如
对教师、学生、管理员三类用户的访问控制）
 数据加密模块（通过数据加密算法实现敏感数据（学生成
绩）在传输和存储过程中不被泄露，保护数据的保密性和
完整性）
 漏洞防御机制（通过安全扫描和漏洞评估，及时发现和修
复系统的安全漏洞）
 安全通信协议（如使用 SSL/TLS，确保数据传输的安全
性）

 网络层：处理数据传输过程中的安全问题，其安全职责是
