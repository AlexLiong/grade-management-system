# 各类详细说明

本文按源码模块说明每个生产类和前端模块的职责、主要入口、协作关系与关键约束。包名均省略公共前缀 `edu.chd.practice`。接口参数和 HTTP 字段的完整定义见 [REST 与 RMI API](06-API接口说明.md)，类之间的图形关系见 [系统模型图](05-模型图.md)。

## 1. `rmi-contract` 分布式契约

该模块不依赖 Spring 和 JDBC，可同时放入 Web JVM 与 RMI JVM。所有跨进程对象都显式实现 `Serializable`，协议版本通过 `serialVersionUID` 和密文格式前缀控制。

### 1.1 核心接口与工具

| 类/接口 | 详细职责 | 关键约束 |
| --- | --- | --- |
| `contract.Canonicalizable` | 所有需要签名的值传递对象的共同接口，要求提供稳定的 `canonicalForm()`。 | 规范串必须与集合迭代顺序、平台编码和对象地址无关。 |
| `contract.CanonicalForms` | 把空值、标量、Map、集合等编码为长度分隔的确定性文本，供 HMAC 和幂等摘要复用。 | Map 按键稳定排序，避免 Web 与 RMI 对同一请求计算出不同签名。 |
| `contract.RequestSignatures` | 使用 HMAC-SHA-256 对操作名、规范化 payload 和调用身份信封签名，并使用常量时间比较验签。 | 密钥不少于 32 字节；签名同时绑定主体、角色、请求号、时间戳和 nonce。 |
| `contract.GradeCipherCodec` | 定义 Web 与 RMI 共用的成绩 JSON 加密格式；从 32 字节主密钥派生 AES 与 HMAC 子密钥，执行 AES-256-GCM、AAD 绑定和完整性校验。 | AAD 绑定 `gradeId`；12 字节 nonce；密文使用版本前缀 `v1`；篡改时失败关闭。 |
| `contract.TimeoutRmiClientSocketFactory` | 为 registry 查找及返回的远程 stub 创建带连接/读取超时的普通或 TLS socket；TLS 模式启用主机名校验。 | 超时必须为正数；序列化后的 factory 保持稳定相等语义。 |
| `contract.RmiBindings` | 集中定义四个注册表绑定名，避免客户端和服务端散落字符串常量。 | 更名属于远程协议变更，必须两端同步升级。 |
| `contract.RemoteServiceException` | 可序列化的受检远程业务异常，携带稳定错误码和低敏感信息量消息。 | 业务拒绝与网络未知结果分开；不能把 SQL、密钥或堆栈送给浏览器。 |
| `contract.SelectInterface` | 远程查询边界，提供 `select` 和 `count`；按课程要求返回 `String[][]`。 | 只接收结构化 `SelectRequest`，不接收 SQL；失败抛 `RemoteServiceException`。 |
| `contract.ManipulationInterface` | 远程写边界，提供单命令、批事务执行和数据库持久化的完成状态探测；按课程要求返回 `boolean`。 | `false` 只表示服务端已确定未提交；结果未知的网络故障必须抛异常；批请求携带幂等键和业务语义指纹，重试先调用 `transactionCompleted`。 |
| `contract.HealthInterface` | 无业务数据的远程健康检查，用于进程启动和 Actuator 依赖状态。 | 不需要用户身份，不返回配置和密钥。 |
| `contract.IntegrityInterface` | 提供账本校验、恢复证据查询、证据解密和受审计恢复。 | 解密/恢复要求管理员、专门权限、原因和有效双人审批；旧链条不可改写。 |

### 1.2 值传递 DTO

| 类 | 详细职责与字段语义 |
| --- | --- |
| `dto.InvocationContext` | RMI 安全信封，保存请求号、数据库可核验的用户名、声明角色、毫秒时间戳、随机 nonce 和 HMAC；`withSignature` 从不可变未签名对象生成签名对象。 |
| `dto.SelectRequest` | 描述资源键、返回列、过滤器、排序、零基页码和页长；自身可规范化签名。 |
| `dto.Filter` | 描述一个允许列表字段、`FilterOperator` 和零到多个字符串值；字段类型在 RMI 服务端转换。 |
| `dto.FilterOperator` | 查询操作符枚举：比较、`LIKE`、字符串字面包含 `CONTAINS`、`BETWEEN`、`IN`、空值判断；`CONTAINS` 会转义通配符，枚举而非任意字符串防止注入 SQL 结构。 |
| `dto.Sort` | 一个排序字段和 `SortDirection`；字段仍须经过 schema 允许列表。 |
| `dto.SortDirection` | 只允许 `ASC` 或 `DESC`，不能携带表达式。 |
| `dto.MutationCommand` | 描述 `INSERT`、`UPDATE`、`DELETE` 的资源、字段值、过滤器、原因和审批标识；不包含 SQL。 |
| `dto.MutationType` | 三类数据操纵枚举，供安全 SQL 生成器进行封闭分派。 |
| `dto.TransactionRequest` | 把一个幂等键、可选业务语义指纹和多条 `MutationCommand` 组成单个远程事务；有语义指纹时，幂等摘要不受重新加密产生的新 nonce/密文影响。 |
| `dto.IdempotencyProbe` | 携带原幂等键和业务语义指纹，供 Web 在重新校验可变业务状态前查询同一主体的事务是否已经提交。 |
| `dto.EncryptedGradePayload` | 传递成绩密文、GCM nonce 和独立 HMAC 标签；明文分项不跨 RMI 数据表接口传输。 |
| `dto.HealthStatus` | 返回 `{healthy, database, serviceVersion, serverTimeEpochMillis}` 四个最小健康字段。 |
| `dto.IntegrityReport` | 返回链是否合法、已校验条目数、第一个坏序号和摘要消息。 |
| `dto.RecoveryQuery` | 用聚合类型、聚合 ID 和上限反向查询外部账本证据。 |
| `dto.RecoveryRecord` | 账本条目的只读传输形式，包含序号、事件、聚合键、受保护快照、前哈希、本条哈希、时间和主体。 |
| `dto.RecoveryEvidenceRequest` | 指定待解密序号和访问原因；原因进入审计。 |
| `dto.RecoveryRestoreRequest` | 指定恢复序号、原因和双人审批请求标识。 |
| `dto.RecoverySnapshot` | 经过链校验、快照解密和成绩 HMAC 校验后的原始字段 Map；只返回授权管理员。 |

## 2. `rmi-server` 数据服务

### 2.1 启动、配置与传输

| 类 | 详细职责 | 主要协作对象 |
| --- | --- | --- |
| `rmi.server.RmiDataServerApplication` | 启动无 Web 容器的 Spring Boot 数据服务并启用配置绑定。 | 所有 RMI Server Bean。 |
| `bootstrap.DemoDataInitializer` | 仅在用户表为空时执行 `demo-data.sql`，保证重启不会覆盖业务数据。 | `JdbcTemplate`、`DataSource`。 |
| `bootstrap.DemoGradeCipherInitializer` | 在演示数据完成后，把空占位成绩变成与 Web 完全相同格式的真实 AES-GCM 密文。 | `GradeCipherCodec`、`SecretMaterialProvider`。 |
| `config.RmiProperties` | 绑定主机、监听地址、registry/service 固定端口、TLS 和 HMAC 文件配置。 | `RmiServiceExporter`、密钥提供器。 |
| `config.SecurityProperties` | 绑定请求时间窗、最大页长、最大事务命令数和成绩主密钥配置。 | 验签、SQL 限制、成绩校验。 |
| `config.LedgerProperties` | 绑定数据库外账本文件路径。 | `HashChainLedger`。 |
| `transport.BoundRmiServerSocketFactory` | 在非 TLS 开发模式把 RMI socket 绑定到明确网卡地址，且实现可序列化的相等语义。 | registry 与远程对象导出。 |
| `transport.BoundSslRmiServerSocketFactory` | 使用 JSSE 创建指定地址的 TLS RMI socket，并可强制客户端证书。 | 生产 RMI mTLS。 |
| `transport.RmiServiceExporter` | 创建固定端口 registry，设置 JEP 290 过滤器，导出并绑定四个远程服务；关闭时逐一解绑和 unexport。 | 四个 Remote 实现、socket factory。 |

### 2.2 远程认证与授权

| 类 | 详细职责 | 安全不变量 |
| --- | --- | --- |
| `security.SecretMaterialProvider` | 从环境或权限受限文件加载 RMI/成绩主密钥；开发模式原子生成，生产模式缺失时失败关闭。 | HMAC 至少 32 字节，成绩主密钥恰好 32 字节，返回 defensive copy。 |
| `security.KeyDerivation` | 以 HMAC-SHA-256 和用途上下文从主密钥派生隔离子密钥。 | 主密钥至少 32 字节；上下文不可为空，不复用原始主密钥作为业务密钥。 |
| `security.RequestAuthenticator` | 校验上下文格式、允许时间窗、HMAC 和 nonce；对已认证重放返回 `false`，使幂等写可读取缓存。 | 先验签后登记 nonce；签名错误和过期请求无条件拒绝。 |
| `security.NonceStore` | 以 `principal + nonce` 保存短期防重放记录并周期清除过期项。 | 同一主体的同一 nonce 在有效窗内只能成功一次。 |
| `security.AuthorizationService` | 将签名中声明角色与数据库活动角色取交集，并执行表级角色、个人权限、教师授课关系、学生本人关系、内部 GATEWAY/SYSTEM/ANALYTICS 投影和状态约束。 | 不信任客户端角色；显式 `granted=false` 高于角色授权；资源查询必须有可验证约束。 |
| `security.SnapshotCrypto` | 用用途隔离的 AES-GCM 密钥加密外部账本中的整行恢复快照。 | 固定格式版本和 AAD；快照在账本文件中也不可读。 |

### 2.3 SQL、事务与远程实现

| 类 | 详细职责 | 关键行为 |
| --- | --- | --- |
| `sql.SchemaRegistry` | 注册每个稳定资源键的真实表或只读视图、列、JDBC 类型、可读角色和可写角色；包含嵌套 `TableDefinition`、`ColumnDefinition`。 | 请求中的表列只有在注册表中出现才能进入 SQL；`teacher_history_courses` 与 `teacher_course_historical_grades` 均只允许教师读取且没有任何写角色。 |
| `sql.ColumnType` | 把字符串协议值严格转换为 String、整数、十进制、布尔、日期或时间戳 JDBC 参数。 | 错误类型在执行前失败，`null` 与空字符串语义分离。 |
| `sql.DatabaseDialect` | 封装 H2/MySQL、SQL Server、Oracle 分页语法并根据产品名选择枚举。 | 只改变 SQL 结构差异，不改变业务请求。 |
| `sql.DatabaseDialectResolver` | 从 `DataSource` 元数据延迟解析并缓存当前数据库方言。 | 未支持产品启动/首次查询时明确失败。 |
| `sql.PreparedSql` | 保存生成后的 SQL、类型化参数和返回列顺序。 | SQL 与参数分离，供执行器绑定。 |
| `sql.SafeSqlBuilder` | 从 DTO 自动生成 SELECT、COUNT、INSERT、UPDATE、DELETE 和证据快照查询。 | 值全部使用 `?`；更新/删除必须有过滤器；限制过滤器、IN 数量和页长；默认稳定排序。 |
| `sql.JdbcPreparedExecutor` | 使用 `PreparedStatement` 绑定参数，执行查询、计数和更新，并把 JDBC 时间/数字规范化为跨数据库稳定字符串。 | 不使用字符串值拼接；返回列顺序与请求一致。 |
| `service.SelectRemoteService` | 完成验签、防重放、远程授权、方言解析和安全查询，返回二维字符串或计数。 | 查询失败抛稳定远程异常，不泄露 SQL。 |
| `service.IdempotencyService` | 以主体和业务幂等键摘要为数据库主键，保存语义请求摘要与提交结果；数据库探测确认同键同语义的历史提交，并拒绝同键异语义。 | 幂等记录与业务命令处于同一数据库事务，只有完整提交后探测才返回完成。 |
| `service.ManipulationRemoteService` | 远程写总协调器：提供事务完成状态探测，预授权每条命令、捕获成绩前后值、验证成绩 HMAC/状态/版本/审批、执行本地数据库事务、写历史、审计、幂等和外部事件；身份/权限写入时锁定管理员角色并重算最终有效权限。 | 任一数据库命令失败全部回滚；探测按主体、幂等键和语义指纹匹配数据库记录；事务最终必须保留一名启用且同时拥有 `ADMIN`、`USER_MANAGE`、`PERMISSION_MANAGE` 的账号；外部账本同步追加并失败关闭但不参加 XA，账本追加后最终 DB commit 失败时可能留下孤立条目。 |
| `service.AuditService` | 在 RMI 数据库内记录远程主体、操作、资源、结果、请求号和低敏详情。 | 不记录签名、密钥、JWT 或明文成绩。 |
| `service.HealthRemoteService` | 执行数据库 `SELECT 1` 并返回数据库产品、服务版本和服务器时间。 | 不检查外部账本，不修改数据；失败返回 `healthy=false`。 |
| `service.IntegrityRemoteService` | 对四类完整性远程方法执行验签、角色/权限/原因/审批检查，并调用账本或恢复服务。 | 解密和恢复权限高于单纯链校验权限。 |
| `service.GradeRecoveryService` | 从有效账本条目解密整行，二次验证聚合 ID 与成绩 HMAC，在数据库事务内插入/替换成绩、写恢复历史并消费审批，同时同步追加新链事件。 | 只从完整有效链恢复；外部 append 失败则关闭，但不参加数据库 XA；恢复本身不覆盖旧证据。 |

### 2.4 外部完整性账本

| 类 | 详细职责 |
| --- | --- |
| `integrity.LedgerEvent` | 内部不可变事件，描述事件类型、聚合类型/ID、加密快照和操作者。 |
| `integrity.GradeSnapshotCodec` | 将成绩整行字段按键排序并逐值 Base64URL 编码，支持空值和版本头，避免分隔符歧义。 |
| `integrity.HashChainLedger` | 在数据库外文件上加进程内锁和文件锁，校验现有链后批量追加；每项 HMAC 覆盖序号、时间、事件、快照和前哈希；支持全链校验、聚合查询和按序号读取。 |

`HashChainLedger.verify()` 只验证当前文件中现存条目的序号、前哈希和 HMAC，不与数据库行自动对账。数据库成绩密文三元组篡改由读解密路径的逐行 HMAC 拒绝；数据库行删除、未认证元数据修改、整份账本缺失和合法尾部截断，需要数据库审计、备份及外部 head/count 锚点共同发现。

### 3.3 Web 安全与错误处理

| 类 | 详细职责 | 关键约束 |
| --- | --- | --- |
| `security.UserPrincipal` | Spring Security 主体，保存稳定用户 ID、用户名、显示名、组织、角色和有效权限，并生成 authorities。 | `hasPermission` 是 Web 业务层入口；RMI 仍从数据库二次验证。 |
| `security.JwtService` | 生成并验证带 issuer、过期时间和唯一 `jti` 的 HMAC JWT，并维护到期自动清理的注销拒绝表。 | 只从 HttpOnly Cookie 使用；撤销表仅在当前 JVM 内存，重启丢失且多实例不共享；生产密钥缺失时启动失败。 |
| `security.JwtAuthenticationFilter` | 从 Cookie 解析 JWT，再通过 RMI 按用户 ID刷新当前账号状态、角色和权限后建立 SecurityContext。 | 不信任令牌内的旧权限，不从 query/header 接受替代 token；账号禁用或权限撤销作用于现有会话，RMI 故障保持 503。 |
| `security.LoginRateLimiter` | 分别按规范化 IP 和规范化用户名维护滑动时间窗失败次数。 | 登录成功只清除用户名计数，IP 维度继续约束来源；分布式部署需共享存储。 |
| `security.SecuritySupport` | 从 SecurityContext 获取类型安全的 `UserPrincipal`，未登录时抛统一异常。 | 业务服务不接受浏览器传入的主体替代值。 |
| `crypto.SecretMaterialLoader` | 从环境/文件加载或开发时原子生成 Base64 密钥并限制文件权限。 | 生产使用外部绝对路径或环境秘密。 |
| `crypto.GradeCryptoService` | 对领域 JSON 调用共享 `GradeCipherCodec`，暴露 `ProtectedGrade`，并把篡改转换为冲突错误。 | 主密钥恰好 32 字节，AAD 为成绩 ID。 |

| `service.TeacherGradeService` | 组合维护同一学生的正考分项和补考原始/计分/状态；加密后批量暂存；用 `MAKEUP_CLEAR` 受控清空未提交补考草稿；状态与版本过滤提交/撤回；统计、已保存分析、历史和异常检测；通过 `teacher_course_historical_grades` 对本人已结课、已提交成绩执行同条件精确 `count` 和真实数据库分页，仅解密当前页，不受 500 条内存截断影响。 | 补考仅对未及格且正考已提交记录开放；清空只移除补考原始/有效分并恢复正考最终分，保留 `makeupStatus=DRAFT`，外层状态仍为 `SUBMITTED`；无已保存分数或已提交补考不会写入；计分 `min(raw,60)`；历史查询始终带当前教师 `teacher_id`，RMI 再按签名主体校验教师所有权；班级均值相对历史绝对偏移至少 10 分、同记录历史版本或该教师本人已结课班中的学生历史成绩相差超过 20 分、补考卷面低于 30 或高于 90 时提示；已提交正考不可覆盖。 |

| `service.RiskAnalysisService` | 从同一课程至少三学年受限投影提取平时、实验、期末样本，训练 OLS 与 CART，为教师批量或学生本人生成区间、概率、风险级别和解释；预测期末比历史期末均值至少低 10 分时追加解释提示。 | 预测与低于历史均值的提示均只存在于响应，不持久化；训练和预测前做授课/本人权限检查。 |
| `service.AdminIdentityService` | 分页管理人员，事务性创建用户+角色+学生/教师档案，软禁用用户，维护组织树、角色权限和个人显式允许/拒绝，并按最终有效权限校验功能依赖。 | 禁止禁用自己；禁止人员分配内部角色；组织有引用或形成环时拒绝；Web 预检最后有效管理员，RMI 在事务提交前再次原子校验。 |
| `service.AdminSecurityService` | 查询审计与告警、处理告警、校验外部链、查询和预览恢复证据。 | 预览必须有原因与专门恢复权限。 |
| `service.GradeReversionService` | 为管理员按课程、学生、状态分页检索可操作成绩；小撤销按真实成绩 ID 把已提交记录转草稿；大撤销/原始恢复创建申请，由不同管理员审批后执行删除或恢复；列表关联并返回复核人、意见和时间。 | 大小按业务语义而非数量；读取成绩元数据和执行撤销分别校验所需权限；审批目标在 Web 与 RMI 两层精确匹配。 |
| `service.OcrProxyService` | 校验 HTTPS 请求、权限、供应商 HTTPS URL/host、文件大小、MIME 和 magic bytes，在内存调用受控 OCR，提取允许字段并在 finally 清零字节数组。 | 可接受文件低于 multipart 内存阈值，不落地临时图片；未配置时明确 503；超时由配置限制。 |

### 3.6 分析算法类

| 类 | 详细职责 |
| --- | --- |
| `analytics.MultipleLinearRegression` | 用带截距正规方程和带主元高斯消元拟合多个自变量的 OLS，返回系数、R²、残差标准误和 95% 预测区间。它校验矩阵维度、有限值、样本数和奇异矩阵。 |
